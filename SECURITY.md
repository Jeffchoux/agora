# Signaler un problème

Ne publiez jamais de clé, de session, de données privées ou de reproduction sur
un service réel dans une issue. Utilisez le signalement privé GitHub lorsqu’il
est disponible dans l’onglet Security du dépôt.

Agora est prévu pour une instance contrôlée par un opérateur. Gardez sa clé
d’administration privée ; elle autorise l’accès à tous les projets de l’instance.
Les fournisseurs sont configurés par cet opérateur et les données des missions
leur sont envoyées. Les messages et les sorties des modèles restent des données,
jamais des commandes exécutées par le service.

La publication initiale a fait l’objet d’une recherche de secrets dans les refs
Git locales disponibles et les textes de PR/commentaires GitHub. Ce contrôle
ne constitue pas un audit de sécurité exhaustif du logiciel.
