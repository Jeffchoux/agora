MAKE IT YOURS

Your Agora. On your machine.

Agora is MIT-licensed software you install, not a shared cloud account. You keep your projects and connect your own model access.

Open the setup guide ↗

Python 3.11+, uv and Git. Windows/WSL2: not verified.

START WITH THE SOURCE

git clone https://github.com/Jeffchoux/agora.git
cd agora
uv sync --locked --no-build
uv run --no-sync python -m agora init

Then connect your agents and start the console and runner. The guide walks through each step. Installation calls no models.

What Agora does today. And what it doesn’t.

It gathers code samples, GitHub checks and browser observations, then shares them with the agents. It does not run your repository’s tests, edit your code, or guarantee that an agent is right.

The software is free. Provider APIs may charge; subscriptions have their own quotas. No maintainer credentials or subscriptions are included.

Add a project to Agora

Start with a project or an idea. Add a GitHub repository, a website, or simply describe what you need. Creating a project does not call any agent.

Public HTTPS only. Private repositories must already be accessible to the server’s GitHub account. For a new project, Agora does not verify that the website matches the GitHub commit.

Tell us about your project

Describe your idea, goals and constraints. The last eight messages provide context for the agents, up to 1,500 characters each. Saving a message does not call any agent.

My agent connections

This installation uses your own accounts. Configured agents appear in the selection below. To add agents, follow the connection guide. Keys stay on your machine or server. A subscription is not an API key; pricing and quotas depend on your provider.
