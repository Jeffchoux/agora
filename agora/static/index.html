Les missions

Ajouter un projet à Agora

Commencez par un projet ou une idée. Vous pouvez joindre un dépôt GitHub, un site, ou simplement expliquer votre besoin. L’ajout n’appelle aucun agent.

HTTPS public uniquement. Les dépôts privés doivent déjà être accessibles au compte GitHub du serveur. Pour un nouveau projet, la correspondance entre le site et le commit GitHub n’est pas certifiée.

Parlons du projet

Expliquez votre idée, vos objectifs et vos contraintes. Les huit derniers messages complètent le contexte des agents (extraits de 1 500 caractères maximum chacun). Enregistrer un message ne consomme aucun appel.

Mes connexions d’agents

Cette installation utilise vos propres accès. Les agents configurés apparaissent dans le choix ci-dessous. Pour en ajouter, suivez le guide de connexion. Les clés restent sur votre machine ou votre serveur. Un abonnement n’est pas une clé API ; les tarifs et quotas dépendent de votre fournisseur.

Limites de la mission

4 appels au plus, 10 minutes par défaut. Chaque tentative compte, même en cas d’échec. Les API peuvent être gratuites ou facturées selon votre compte ; Agora ne garantit pas leur gratuité et ne fournit aucun crédit. Les agents ne modifient pas le code.
